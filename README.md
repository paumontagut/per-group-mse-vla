# Project page

This branch hosts the GitHub Pages site for the paper
*Per-Group Error, Not Total MSE: Fine-Tuning Vision-Language-Action
Models for 11-DoF Mobile Manipulation* (ICRA 2026 Workshop "From Data
to Decisions", 1st place out of 36 teams).

Live at
[paumontagut.github.io/per-group-mse-vla](https://paumontagut.github.io/per-group-mse-vla/).

The page is a single static `index.html` with a small CSS file and a
few media assets. To preview locally, run any static server in this
directory.

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

The main code, the model card and the documentation live on the `main`
branch.
